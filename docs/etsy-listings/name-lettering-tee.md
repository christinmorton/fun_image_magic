## Filling an order

1. Lettering screen: **B** for a plain background, then the name with **N** and the style with **1**.
2. Save it (S). The lettering is saved as a transparent PNG.
3. **Cover Studio needs one addition for this:** an export of the lettering alone, sized for
   the tee, instead of the whole cover. Until then, place `lettering.png` on the provider's
   print area by hand.
4. Send a proof, then the file to the provider.
